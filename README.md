# 🤖 CalcAI — Intelligent Calculator Agent

CalcAI is a modern, AI-inspired calculator interface designed to make calculations simple, fast, and interactive.

Instead of using a traditional calculator, users can enter calculation queries in natural language, such as:

> "Calculate 18% GST on ₹5000"

CalcAI processes the query and displays the result along with a clear step-by-step explanation.

* 🧠 Natural-language style calculation input
* 🧮 Basic mathematical calculations
